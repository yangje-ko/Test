SecureIdentity SSO/EAM

Web·CS 환경을 위한
통합인증 & 권한관리 플랫폼

SecureOn의 SecureIdentity는 SSO와 EAM을 단일 제어면으로 통합해 복잡한 Web/CS 업무 시스템, ERP, 그룹웨어, 금융·제조 핵심 자원까지 하나의 정책으로 보호합니다. PKI 기반 인증, OTP, 생체 인증, 보안 토큰까지 확장 가능한 아이덴티티 보안 체계를 제공합니다.

Solution blueprint

SSO/EAM 대상 업무 시스템 구성도

SecureIdentity는 SafeAgent, Policy Server, Repository, Policy Manager로 구성되며
업무 시스템과의 연동을 통해 사용자 인증과 권한을 중앙에서 제어합니다.

사용자 시스템 접속 → 통합 인증 요청
SafeAgent 업무 시스템별 설치, 로그인 모듈/SSO API 연동
Policy Server 인증/권한 정책 적용, 세션·토큰 발급, 중복 로그인 차단
Repository (LDAP) 사용자 인증 정보, 권한 정책, 감사 로그 저장
Policy Manager Web GUI 기반 관리자 콘솔, 감사/통계/환경 설정
구성 모듈 기능 설명
Client Manager CS 프로그램과 연동되는 인증 모듈 배포, 설치 자동화 (Cab/Agent 패키지).
SSO Agent 로그인 서버와 연동되는 SSO Engine, 암호화 토큰 생성/검증, 다양한 언어(C/Java/ASP/.NET) API 제공.
Safe Agent for ERP/Siebel/SAP/Notes 주요 업무 패키지에 특화된 인증/권한 연동 Agent 제공으로 빠른 통합.
Safedentity Manager 역할 기반 권한 관리, 감사, WorkFlow, 스케줄러, 백업 기능을 제공하는 Spring 기반 Web 콘솔.
Monitoring & Audit 사용자 로그인 감사, 세션 검증, Agent 상태·CPU·메모리·DISK 사용률 모니터링.

Core capabilities

주요 기능 하이라이트

1. 단일 인증 프로세스

분산 환경에서 통합 인증을 제공하며, 보안 SSO 토큰을 Cookie/Parameter로 전달하여 App 간 세션을 공유합니다.

2. 보안 인증 토큰

국가 검증 암호 알고리즘 기반 암호화 구조(Salt, EncKey, MAC)로 사용자 인증 데이터를 보호하고 PKI 연계.

3. 중복 로그인 제어

Policy Server에서 세션을 실시간 검증해 중복 접속을 차단하고 OT/ERP 전용 Agent 연동.

4. 장애 대응

자체 Load Balancing, Fail-Over, Cache 기능으로 별도 L4 없이도 고가용성을 달성.

5. 확장성

ERP·SAP·Oracle·Domino 등 주요 업무 시스템과 연동, ID/PW·PKI·OTP·보안토큰·생체 인증까지 지원.

6. 감사 & 모니터링

사용자 로그인/로그아웃, 세션 검증, 권한 변경 이력에 대한 통계/리포트 제공.

Role based access control

역할 기반 권한 모델

NIST RBAC 표준을 따르는 SecureIdentity는 사용자-역할-권한-자원의 관계를 통해 권한 관리 효율성을 높입니다.
조직 변화나 역할 이동에도 권한을 자동 재배치하여 운영 리스크를 줄입니다.

역할 그룹 인사 / 회계 / 감사 / 운영 등
권한 그룹 READ / WRITE / DELETE / APPROVE
자원 시스템, 화면, 메뉴, 버튼, API
보안 통제 접근 통제, 권한 변경 용이성, 적절한 임무 분리

Deployment methodology

SecureIdentity 구축 절차

1. 설계 단계 가이드라인 작성, 인증 정보 식별, 통합 구축 설계, 테스트 계획 수립으로 각 업무 시스템별 요구사항 정의.
2. 개발/환경 구축 개발 환경 및 패키지 설치, LDAP/DB 구조 설계, 권한 정보 등록, SafeAgent 배포.
3. 연동 & 검증 각 업무 시스템과 SSO/EAM API 연동, Policy Server 설정, 단위/통합 테스트 및 Fail-Over 검증.
4. 운영 / 모니터링 Safedentity Manager에서 권한 운영, 감사/보고서 자동화, Agent 상태/사용량 실시간 모니터링.
