# 📝 메모 앱 (Memo App)

React로 만든 간단하고 직관적인 메모 관리 애플리케이션입니다. Create React App(CRA)을 기반으로 제작되었으며, 로컬 스토리지를 활용하여 브라우저에 메모를 저장합니다.

## ✨ 주요 기능

### 1. 새 메모 생성
- "➕ 새 메모" 버튼을 클릭하여 새로운 메모를 생성합니다
- 새 메모 생성 시 즉시 수정 모드로 전환되어 바로 입력할 수 있습니다
- 제목 입력 필드에 자동으로 포커스가 설정됩니다

### 2. 메모 수정
- 각 메모의 "✏️ 수정" 버튼을 클릭하여 수정 모드로 전환합니다
- 제목과 내용을 자유롭게 편집할 수 있습니다

### 3. 메모 저장
- 수정 모드에서만 "💾 저장" 버튼이 표시됩니다
- 저장 버튼을 클릭하면 메모가 저장되고 수정 모드가 종료됩니다
- "취소" 버튼을 통해 변경사항을 취소할 수 있습니다

### 4. 메모 삭제
- 각 메모의 "🗑️ 삭제" 버튼을 클릭하여 메모를 삭제합니다
- 삭제 시 확인 없이 즉시 삭제됩니다

### 5. 메모 검색
- 상단 검색창에서 메모의 제목 또는 내용을 검색할 수 있습니다
- 검색 결과에 해당하는 메모만 필터링되어 표시됩니다
- 검색어를 지우면 모든 메모가 다시 표시됩니다

## 🚀 시작하기

### 사전 요구사항

- Node.js (v14 이상 권장)
- npm 또는 yarn

### 설치 방법

1. 저장소를 클론하거나 프로젝트 디렉토리로 이동합니다:
```bash
cd MEMO-APP
```

2. 의존성을 설치합니다:
```bash
npm install
```

### 실행 방법

개발 서버를 시작합니다:
```bash
npm start
```

브라우저에서 [http://localhost:3000](http://localhost:3000)이 자동으로 열립니다.

### 빌드 방법

프로덕션용 빌드를 생성합니다:
```bash
npm run build
```

빌드된 파일은 `build` 폴더에 생성됩니다.

## 🛠️ 사용된 기술

- **React** (v19.2.4) - UI 라이브러리
- **React DOM** (v19.2.4) - React DOM 렌더링
- **React Scripts** (v5.0.1) - Create React App 빌드 도구
- **LocalStorage** - 브라우저 로컬 스토리지를 활용한 데이터 저장

## 💾 데이터 저장

모든 메모는 브라우저의 로컬 스토리지에 저장됩니다. 따라서:
- 같은 브라우저에서 메모가 유지됩니다
- 브라우저를 닫았다가 다시 열어도 메모가 보존됩니다
- 다른 브라우저나 기기에서는 메모가 공유되지 않습니다
- 브라우저 데이터를 삭제하면 메모도 함께 삭제됩니다

## 🎨 주요 특징

- **반응형 디자인**: 모바일과 데스크톱에서 모두 잘 작동합니다
- **직관적인 UI**: 깔끔하고 사용하기 쉬운 인터페이스
- **자동 저장**: 메모를 수정하면 자동으로 로컬 스토리지에 저장됩니다
- **실시간 검색**: 검색어를 입력하는 즉시 결과가 필터링됩니다
- **날짜 표시**: 메모의 생성 시간과 수정 시간을 표시합니다

## 📝 사용 예시

1. **새 메모 만들기**
   - "➕ 새 메모" 버튼 클릭
   - 제목과 내용 입력
   - "💾 저장" 버튼 클릭

2. **메모 검색하기**
   - 상단 검색창에 키워드 입력
   - 관련된 메모만 자동으로 필터링되어 표시됨

3. **메모 수정하기**
   - 메모의 "✏️ 수정" 버튼 클릭
   - 내용 수정 후 "💾 저장" 클릭

4. **메모 삭제하기**
   - 메모의 "🗑️ 삭제" 버튼 클릭
